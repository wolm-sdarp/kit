# Typst — зарезервировано

Формат `kit-typst` в версии 0.1 не реализован. Что уже подготовлено:

- `brand/light.yml` — цвета и назначение шрифтов (Typst берёт светлую тему);
- `fonts/ttf/` — полные variable-шрифты для `font-paths` (кириллица и дореформенные буквы есть);
- классы `.lab-*`, кастомные колауты и crossref-типы описаны в README kit как контракт:
  в Typst их будет реализовывать lua-фильтр `shared/filters/wolm.lua`.

Заготовка формата — закомментированный блок `typst:` в `_extension.yml`.
Проверено на Quarto 1.9.37: `font-paths` разрешается относительно расширения;
шаблон книги (orange-book) требует `author`.
